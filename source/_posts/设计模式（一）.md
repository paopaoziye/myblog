# 计算机基础
## 设计模式
### 设计模式（一）
#### 引言
**①简介**
>**概述**：设计模式是针对**常见软件设计问题**的可复用方案，通过明确对象或模块的**分工与协作方式**，使代码更易**维护和扩展**
{%list%}
设计模式主要涉及对象的创建、组合与交互，可分为创建型、结构型和行为型，分别关注对象的创建方式、组织结构及协作机制
{%endlist%}
{%right%}
设计模式通过降低模块间的耦合、隔离容易变化的部分，减少需求变更时对其他代码的影响，提高软件的可维护性和扩展性
{%endright%}
{%warning%}
设计模式通常会引入额外的接口和抽象，增加一定的代码复杂度与维护成本，应根据实际需求和项目规模合理选择，避免过度设计
{%endwarning%}
**②面向对象**
>**概述**：面向对象是一种**程序设计思想**，将**数据以及操作数据的行为**组织为对象，并通过对象之间的协作完成程序功能
{%list%}

{%endlist%}
面向过程（Procedural Programming）主要围绕操作过程和函数调用来组织程序
对象是具有独立身份、状态和行为的程序实体
类是用于描述一类对象的数据与行为的定义，对象则是依据该定义创建的具体实例
封装是将对象的数据和相关操作组织在一起，并控制外部对其内部状态与实现细节的访问，设计时通常希望外部通过明确的操作接口访问或修改设备状态，而不是任意修改内部成员，在 C 语言中，可以使用文件作用域 static、不透明结构体以及模块 API 来隐藏内部细节

继承是一种建立类型层次关系的机制，使新类型能够在已有类型基础上继承和扩展相关成员及行为

多态是指通过统一的操作接口，让不同类型的对象执行各自对应的行为，在 C 语言中，可以通过函数指针和操作表实现这种运行时多态
{%right%}

{%endright%}
{%warning%}
面向对象并不是单纯地把数据放进结构体，也不是把所有函数包装起来，而是围绕对象的职责来组织数据、行为和协作关系
{%endwarning%}
```c
/* 面向过程的编程思路 */
void uart_init(void);
void uart_send(const char *data);

int main(void)
{
    uart_init();
    uart_send("Hello");

    return 0;
}
```
```c
/* 面向对象的编程思路 */
#include <stdio.h>

typedef struct {
    unsigned port;
    unsigned baudrate;
    unsigned tx_count;
} Uart;

void uart_init(Uart *self,
               unsigned port,
               unsigned baudrate)
{
    self->port = port;
    self->baudrate = baudrate;
    self->tx_count = 0;
}

void uart_send(Uart *self, const char *data)
{
    /* PC上的模拟输出，不是真实硬件发送 */
    printf("UART%u: %s\n", self->port, data);
    self->tx_count++;
}

int main(void)
{
    Uart uart1;
    Uart uart2;

    uart_init(&uart1, 1, 115200);
    uart_init(&uart2, 2, 9600);

    uart_send(&uart1, "Hello");
    uart_send(&uart2, "World");

    return 0;
}
```
