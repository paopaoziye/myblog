# 处理器架构
## ARM体系架构
### ARM体系架构（三）
#### 常用指令
**①数据传输**
>**概述**：主要用于在**立即数**、**寄存器**和**内存**之间传递数据，常用指令有`MOV`、`ADR`、`LDR`、`STR`、`PUSH`和`POP`等
{%list%}
ARM采用典型的Load/Store架构，处理器的算数和逻辑运算通常只作用于寄存器操作数，内存数据需先装入寄存器再进行运算
{%endlist%}
>`MOV`主要用于**寄存器之间**或**立即数到寄存器**的数据传递，基本语法为`MOV Rd, Operand`，表示`Rd = Operand`

>`ADR`主要用于**获取标签对应地址**，常用于访问**代码段或数据段**中的静态对象，基本语法为`ADR Rd, label`，表示`Rd = &label`

>`LDR`主要用于**从内存中加载数据到寄存器**，是访问**内存数据**的主要方式，基本语法为`LDR Rd, [Rn]`，表示`Rd = Memory[Rn]`

>`STR`主要用于**将寄存器中的数据写入内存**，从而**保存计算结果**或**修改内存数据**，基本语法为`STR Rd, [Rn]`，表示`Memory[Rn] = Rd`

>`PUSH`主要用于**将一个或多个寄存器的数据压入栈中**，从而**保存寄存器现场**，基本语法为`PUSH {register_list}`

>`POP`主要用于**从栈中取出保存的数据并写回指定寄存器**，常用于**函数返回**或**恢复执行环境**，基本语法为`POP {register_list}`
{%right%}
LDM/STM用于在连续内存与多个寄存器之间进行批量数据传输，并通过IA/IB/DA/DB指定地址变化方式，提高传输效率
{%endright%}
>`LDM`主要用于**从连续内存中批量读取数据到多个寄存器**，基本语法为`LDM Rn{!}, {register_list}`

>`STM`主要用于**将多个寄存器的数据批量写入连续内存**，基本语法为`STM Rn{!}, {register_list}`

>`!`表示**基址回写**，表示批量传输完成后，把**最终计算得到的地址**重新写回**基址寄存器**`Rn`，常用于**数组遍历**和**栈指针维护**

>`I/D`表示**地址变化方向为递增/递减**，`A/B`表示**地址更新**在**访问后/前**，缺省采用`IA`方式，即**先访问当前地址随后`Rn`递增**
{%warning%}
LDR和STR默认传输32位数据，可通过添加B/H后缀指定访问的数据宽度，LDR还可通过SB/SH指定读取后的符号扩展方式
{%endwarning%}
>`STRB/STRH r0, [r1]`表示把寄存器`r0`的**低**`8/16`位数据写入寄存器`r1`指定的**内存地址**

>`LDRB/LDRH r0, [r1]`表示从寄存器`r1`指向的**内存地址**中读取`8/16`位数据，并将其**零扩展**为`32`位后写入整个`r0`寄存器

>`LDRSB/LDRSH r0, [r1]`表示从寄存器`r1`指向的**内存地址**中读取`8/16`位数据，并将其**符号扩展**为`32`位后写入整个`r0`寄存器

>**零扩展**表示将数据高位全部补`0`，**符号扩展**表示根据**最高有效位**复制填充高位，`0xFF`对应扩展分别为`0x000000FF`和`0xFFFFFFFF`
{%wrong%}
上述数据传输指令主要用于访问通用寄存器R0-R15，CPSR/SPSR等特殊寄存器需要使用MRS/MSR等专用指令进行读取和修改
{%endwrong%}
```nasm
; 1.寄存器与地址
MOV R1, R0            ; R1 = R0
MOV R1, #0x10         ; R1 = 0x10
MVN R1, R0            ; R1 = ~R0
MOVW R1, #0x5678      ; R1低16位 = 0x5678，高16位清0
MOVT R1, #0x1234      ; R1高16位 = 0x1234，低16位保持不变
ADR R1, label         ; R1 = &label，取得label对应的地址

; 2.特殊寄存器
MRS R2, PSP           ; R2 = PSP
MSR PSP, R3           ; PSP = R3

; 3.读取内存
LDR R1, [R0]          ; 从R0指向的内存读取32位数据到R1
LDRB R1, [R0]         ; 读取8位数据，零扩展为32位后写入R1
LDRH R1, [R0]         ; 读取16位数据，零扩展为32位后写入R1
LDRSB R1, [R0]        ; 读取8位有符号数据，符号扩展为32位后写入R1
LDRSH R1, [R0]        ; 读取16位有符号数据，符号扩展为32位后写入R1
LDR R1, [R0, #4]      ; 从R0+4地址读取32位数据到R1，R0不变
LDR R1, [R0, #4]!     ; 先R0 = R0+4，再从新R0地址读取32位数据到R1
LDR R1, [R0], #4      ; 先从R0地址读取32位数据到R1，再R0 = R0+4

; 4.批量读取
LDMIA R0!, {R1-R4}    ; 从R0开始向高地址连续读取4个32位数据到R1-R4，结束后R0 = R0+16
LDMIB R0!, {R1-R4}    ; 从R0+4开始向高地址连续读取4个32位数据到R1-R4，结束后R0 = R0+16
LDMDA R0!, {R1-R4}    ; 向低地址方向读取连续数据到R1-R4，结束后R0 = R0-16
LDMDB R0!, {R1-R4}    ; 基址先向低地址移动再读取连续数据到R1-R4，结束后R0 = R0-16
POP {R0-R3, PC}       ; 从栈中恢复R0-R3和PC，语义上对应LDMIA SP!, {R0-R3, PC}

; 5.写入内存
STR R1, [R0]          ; 将R1的32位数据写入R0指向的内存
STRB R1, [R0]         ; 将R1低8位写入R0指向的内存
STRH R1, [R0]         ; 将R1低16位写入R0指向的内存
STR R1, [R0, #4]      ; 将R1写入R0+4地址，R0不变
STR R1, [R0, #4]!     ; 先R0 = R0+4，再将R1写入新R0地址
STR R1, [R0], #4      ; 先将R1写入R0地址，再R0 = R0+4

; 6.批量写入
STMIA R0!, {R1-R4}    ; 从R0开始向高地址连续写入R1-R4，结束后R0 = R0+16
STMIB R0!, {R1-R4}    ; 从R0+4开始向高地址连续写入R1-R4，结束后R0 = R0+16
STMDA R0!, {R1-R4}    ; 向低地址方向连续写入R1-R4，结束后R0 = R0-16
STMDB R0!, {R1-R4}    ; 基址先向低地址移动再连续写入R1-R4，结束后R0 = R0-16
PUSH {R0-R3, LR}      ; 将R0-R3和LR压入栈，语义上对应STMDB SP!, {R0-R3, LR}
```
**②数据运算**
>**概述**：主要用于对**寄存器中的数据**进行**算术运算**、**逻辑运算**及**移位操作**，常用指令有`ADD`、`SUB`、`MUL`、`AND`和`LSL`等
{%list%}
ARM数据运算通常以寄存器或立即数作为操作数，并支持将移位操作与算术或逻辑运算结合执行，从而减少额外的数据处理指令
{%endlist%}
>`ADD`表示**加法运算**，`SUB`表示**减法运算**，`MUL`表示**乘法运算**，其中`MUL`仅保留**乘积结果**的低`32`位

>`SDIV`和`UDIV`表示**有符号整数除法**和**无符号整数除法**，即`SDIV`将**最高位作为符号位**，按照**补码**计算，`UDIV`将**所有位作为数值位**

>`AND`表示**按位与运算**，`ORR`表示**按位或运算**，`EOR`表示**按位异或运算**，`BIC`表示**按位清除指定比特**

{%right%}
移位与旋转指令主要用于快速实现乘除2的幂、数据位调整、地址计算以及通信数据解析，并且可以与算术或逻辑指令组合执行
{%endright%}
>`LSL`表示**逻辑左移**，低位补`0`，常用于实现**乘以**`2`的幂，`LSR`表示**逻辑右移**，高位补`0`，常用于**无符号数据除以**`2`的幂

>`ASR`表示**算术右移**，右移过程中**高位补符号位**，确保负数移动后任保持**正确的符号**，常用于**有符号数据除以**`2`的幂

>`ROR`表示**循环右移**，数据右移后**移出的低位重新进入高位**，保持所有**比特信息不变**，常用于**位模式处理**和**密码算法**

{%warning%}
ADD、SUB和MUL等普通数据运算指令只保存32位结果，超过32位的数据计算需要配合ADC、SBC或长乘法指令保存高位结果
{%endwarning%}
>`ADC`表示**带进位加法**，`SBC`表示**带借位减法**，通过引入**进位标志**`C`完成进位和借位运算，实现**高精度多字节加减法**

>`UMULL`和`SMULL`表示**无符号长乘法**和**有符号长乘法**，通过**两个寄存器**`RdHi`和`RdLo`分别保存结果的高`32`位和低`32`位
{%wrong%}
上述数据处理指令默认只修改目标寄存器，并不会自动更新条件标志位，如果需要根据运算结果更新状态标志，需要添加S后缀
{%endwrong%}
```nasm
; 1.算术运算
ADD R0, R1, R2          ; R0 = R1 + R2，两个寄存器相加
ADD R0, R1, #10         ; R0 = R1 + 10，寄存器与立即数相加
SUB R0, R1, R2          ; R0 = R1 - R2，两个寄存器相减
SUB R0, R1, #10         ; R0 = R1 - 10，寄存器减去立即数
MUL R0, R1, R2          ; R0 = R1 × R2，保留乘积低32位
SDIV R0, R1, R2         ; R0 = R1 ÷ R2，按照有符号整数进行除法
UDIV R0, R1, R2         ; R0 = R1 ÷ R2，按照无符号整数进行除法

; 2.逻辑运算
AND R0, R1, R2          ; R0 = R1 & R2，按位与运算，用于提取指定比特
ORR R0, R1, R2          ; R0 = R1 | R2，按位或运算，用于设置指定比特
EOR R0, R1, R2          ; R0 = R1 ^ R2，按位异或运算，用于数据翻转
BIC R0, R1, R2          ; R0 = R1 & ~R2，清除R2中对应位置的比特

; 3.移位运算
LSL R0, R1, #2          ; R0 = R1 << 2，逻辑左移2位，等价于乘以4
LSR R0, R1, #2          ; R0 = R1 >> 2，逻辑右移2位，用于无符号除以4
ASR R0, R1, #2          ; R0 = R1 >> 2，算术右移2位，用于有符号除以4
ROR R0, R1, #8          ; R0 = R1循环右移8位，低位重新进入高位

; 4.移位结合运算
ADD R0, R1, R2, LSL #2  ; R0 = R1 + (R2 << 2)，先将R2左移2位再执行加法

; 5.高精度运算
ADDS R0, R1, R2         ; R0 = R1 + R2，同时更新N/Z/C/V条件标志
ADC R1, R3, R4          ; R1 = R3 + R4 + C，利用进位完成多字节加法
SBC R1, R3, R4          ; R1 = R3 - R4 - (1-C)，利用进位完成多字节减法

; 6.长乘法
UMULL R0, R1, R2, R3    ; {R1,R0}=R2×R3，保存64位无符号乘法结果
SMULL R0, R1, R2, R3    ; {R1,R0}=R2×R3，保存64位有符号乘法结果
```
**③比较测试**
>**概述**：主要用于对**寄存器中的数据进行比较或位测试**，并更新`N/Z/C/V`等条件标志位，常用指令有`CMP`、`CMN`、`TST`和`TEQ`
{%list%}
比较测试指令通常只执行内部运算并更新条件标志位，不保存计算结果，主要用于数据比较、位状态检测和程序流程控制
{%endlist%}
>`CMP`用于**比较两个数大小**，基本语法为`CMP Rn, Operand`，内部执行`Rn - Operand`并更新条件标志，常用于**条件判断**和**分支跳转**

>`CMN`用于**比较负值**，基本语法为`CMN Rn, Operand`，内部执行`Rn + Operand`并更新条件标志，常用于**判断加法运算后的状态**

>`TST`用于**按位测试**，基本语法为`TST Rn, Operand`，内部执行`Rn & Operand`并更新条件标志，常用于**检测指定比特是否置位**

>`TEQ`用于**按位相等测试**，基本语法为`TEQ Rn, Operand`，内部执行`Rn ^ Operand`并更新条件标志，常用于**判断对应位是否相同**
{%right%}
条件标志位用于记录最近一次运算的结果状态，而条件码根据这些标志决定后续指令是否执行，从而实现条件判断和流程控制
{%endright%}
>`N`表示结果的**符号状态**，**结果最高位**为`1`时置位，`Z`表示结果的**零状态**，当运算结果**全部**为`0`时置位

>`C`表示**进位标志**，当**加法产生最高位进位**或者**减法未发生借位时**置位，用于表示**无符号运算**中的进位状态

>`V`表示**溢出状态**，当**有符号运算结果超出当前位宽可表示范围时**置位，用于判断**有符号数据溢出**
{%warning%}
条件标志位只会在执行特定指令后发生改变，并会一直保持到下一次被修改，因此使用条件码前需要确认当前标志位的来源
{%endwarning%}
```nasm
; 1.数值比较
CMP R0, R1            ; 计算R0-R1并更新条件标志，不保存结果
CMP R0, #10           ; 将R0与10比较，内部计算R0-10
CMN R0, R1            ; 计算R0+R1并更新条件标志，不保存结果
CMN R0, #1            ; 计算R0+1并更新条件标志

; 2.位状态测试
TST R0, #0x01         ; 计算R0 & 0x01，测试bit0是否为1
TST R0, R1            ; 计算R0 & R1，并根据结果更新条件标志
TEQ R0, R1            ; 计算R0 ^ R1，相等时结果为0并使Z=1
TEQ R0, #0xFF         ; 计算R0 ^ 0xFF，并根据结果更新条件标志

; 3.条件标志
CMP R0, R1            ; R0=R1时Z=1，R0-R1结果最高位为1时N=1
CMP R0, #0            ; 常用于判断R0是否等于0、是否为负数
TST R0, #0x08         ; bit3为0时结果为0，Z=1
TEQ R0, R1            ; R0与R1完全相同时异或结果为0，Z=1

; 4.条件码与标志判断
BEQ label             ; Equal，相等，Z=1时跳转
BNE label             ; Not Equal，不相等，Z=0时跳转
BCS label             ; Carry Set，无符号大于等于，C=1时跳转
BCC label             ; Carry Clear，无符号小于，C=0时跳转
BHI label             ; Higher，无符号大于，C=1且Z=0时跳转
BLS label             ; Lower or Same，无符号小于等于，C=0或Z=1时跳转
BMI label             ; Minus，结果为负，N=1时跳转
BPL label             ; Plus，结果非负，N=0时跳转
BVS label             ; Overflow Set，发生有符号溢出，V=1时跳转
BVC label             ; Overflow Clear，未发生有符号溢出，V=0时跳转
BGE label             ; Greater or Equal，有符号大于等于，N=V时跳转
BLT label             ; Less Than，有符号小于，N≠V时跳转
BGT label             ; Greater Than，有符号大于，Z=0且N=V时跳转
BLE label             ; Less or Equal，有符号小于等于，Z=1或N≠V时跳转
```
**④分支跳转**
>**概述**：主要用于**改变程序执行流**，实现**条件判断**、**循环控制**及**函数调用**，常用指令有`B`、`BL`、`BX`和`BLX`
{%list%}
在ARM指令中，B表示分支跳转，L表示链接即保存返回地址到LR用于支持返回，X表示支持A32/T32指令状态切换
{%endlist%}
>`B`表示**无条件分支跳转**，基本语法为`B label`，通过指定标签`label`直接跳转到**目标地址**继续执行

>`BL`表示**带链接的分支跳转**，基本语法为`BL label`，在跳转到`label`对应地址的同时将**返回地址**保存到`LR`寄存器

>`BX`表示**寄存器间接跳转**，基本语法为`BX Rm`，在跳转到`Rm`**保存的地址**同事根据**目标地址最低位**进入`A32`或`T32`指令状态

>`BLX`表示**带链接的状态切换跳转**，基本语法为`BLX Rm/label`，在跳转并支持`A32/T32`状态切换的同时，将**返回地址**保存到`LR`
{%right%}
ARM跳转方式分为相对跳转和绝对跳转，前者通过当前PC加偏移量计算目标地址，后者则直接使用完整目标地址进行跳转
{%endright%}
>`B/BL/BLX label`的机器码通常保存的不是`label`的**完整地址**，而是**目标相对当前`PC`的偏移量**
{%warning%}
相对跳转不依赖代码的绝对位置，但跳转范围受到指令编码位数限制，目标地址过远时需要通过中间跳转等方式实现远距离跳转
{%endwarning%}
{%wrong%}
绝对跳转依赖完整目标地址，如果程序进行重定位后地址发生变化，未正确更新目标地址可能导致跳转错误或访问非法区域
{%endwrong%}
```nasm
; 1.直接跳转
B label               ; 无条件跳转到label继续执行
B loop                ; 跳转到loop，常用于循环
B end                 ; 跳转到end，常用于跳过某段代码

; 2.条件跳转
BEQ label             ; Z=1时跳转，表示相等
BNE label             ; Z=0时跳转，表示不相等
BGT label             ; 有符号大于时跳转，Z=0且N=V
BLT label             ; 有符号小于时跳转，N≠V
BGE label             ; 有符号大于等于时跳转，N=V
BLE label             ; 有符号小于等于时跳转，Z=1或N≠V
BHI label             ; 无符号大于时跳转，C=1且Z=0
BLO label             ; 无符号小于时跳转，C=0

; 3.函数调用
BL function           ; 跳转到function，同时将返回地址保存到LR
BL printf             ; 调用已知函数printf，返回地址保存到LR
BX LR                 ; 跳转到LR保存的返回地址，常用于函数返回

; 4.寄存器间接跳转
BX R0                 ; 跳转到R0保存的地址，并根据目标地址确定A32/T32状态
BX LR                 ; 跳转到LR保存的地址，常用于函数返回
BLX R0                ; 调用R0指向的函数，返回地址保存到LR并支持状态切换
BLX R3                ; 调用R3保存地址对应的函数，常用于函数指针调用

; 5.跨状态调用
BLX function          ; 相对调用function，保存返回地址并切换A32/T32状态，需架构支持
BLX R0                ; 间接调用R0中的目标，保存返回地址并按目标地址切换状态

; 6.相对与间接跳转
B label               ; PC相对跳转，机器码保存目标相对当前PC的偏移量
BL function           ; PC相对函数调用，同时将返回地址保存到LR
BLX function          ; PC相对调用并支持状态切换，需相应A32/T32架构支持
BX R0                 ; 寄存器间接跳转，完整目标地址由R0提供
BLX R0                ; 寄存器间接调用，目标地址由R0提供并保存返回地址

; 7.典型循环
loop:
SUBS R0, R0, #1       ; R0 = R0-1，同时更新条件标志
BNE loop              ; Z=0时返回loop，直到R0减为0

; 8.典型条件判断
CMP R0, R1            ; 比较R0和R1，更新条件标志
BEQ equal             ; R0=R1时跳转到equal
BGT greater           ; R0>R1时按有符号比较跳转到greater
BLT less              ; R0<R1时按有符号比较跳转到less

; 9.典型函数调用与返回
PUSH {R4, LR}         ; 保存R4和当前函数返回地址
BL function           ; 调用function，新返回地址写入LR
POP {R4, LR}          ; 恢复R4和原函数返回地址
BX LR                 ; 跳转到LR，返回上一级调用者
```
**⑤系统指令**
>**概述**：主要用于**处理器状态控制**、**异常中断管理**、**低功耗等待**及**同步操作**，常用指令有`SVC`、`WFI`和`DMB`等
{%list%}
系统指令主要用于处理器运行状态和系统级行为控制，其支持范围、执行权限以及具体功能与ARM架构版本和处理器Profile有关
{%endlist%}
>`SVC`表示**软件触发异常**，基本语法为`SVC #imm`，用于主动进入`SVC`**异常处理程序**，常用于实现操作系统中的**系统调用机制**

>`CPSID`和`CPSIE`分别用于**禁止和使能指定异常响应**，常见语法为`CPSID/CPSIE i`，用于**禁止/使能**`IRQ`响应

>`WFI`表示**等待中断**，基本语法为`WFI`，用于让处理器**停止执行普通指令**，直到**符合条件的中断或异常**唤醒处理器

>`WFE`表示**等待事件**，基本语法为`WFE`，与`WFI`类似，但等待的是**事件信号**，事件通常由`SEV/SEVL`等指令或**硬件机制**产生
{%right%}
屏障指令用于约束处理器的乱序执行、缓存以及写缓冲行为，保证内存访问和外设操作按照预期顺序生效
{%endright%}
>`DMB`表示**数据内存屏障**，用于约束屏障前后的**内存访问顺序**，使其他观察者能够**按照规定顺序**看到数据变化

>`DSB`表示**数据同步屏障**，用于等待屏障之前的**内存访问**和**外设操作**全部完成后，再继续执行**后续指令**

>`ISB`表示**指令同步屏障**，用于清空**流水线中的预取指令**，并重新进行**取指**、**译码**和**执行**，使处理器使用最新状态
{%warning%}
屏障指令会限制处理器的乱序执行和优化能力，过度使用可能降低程序性能，应仅在需要保证执行顺序或数据一致性时使用
{%endwarning%}
{%wrong%}
部分系统指令需要在特权模式下执行，若当前运行级别权限不足，可能触发异常或无法完成预期操作
{%endwrong%}
```nasm
; 1.软件异常
SVC #0                 ; 触发SVC异常，立即数0作为软件调用标识
SVC #1                 ; 触发SVC异常，立即数1作为软件调用标识

; 2.异常中断控制
CPSID i                ; 禁止IRQ响应，常用于进入需要避免中断干扰的临界区
CPSIE i                ; 使能IRQ响应，常用于退出临界区并恢复中断

; 3.等待与唤醒
WFI                    ; 停止普通指令执行，等待符合条件的中断或异常唤醒
WFE                    ; 进入事件等待状态，等待事件到来后继续执行
SEV                    ; 产生事件，可用于唤醒处于WFE等待状态的处理器

; 4.内存与执行屏障
DMB SY                 ; 约束屏障前后的内存访问顺序，常用于多核共享数据和外设访问排序
DSB SY                 ; 等待屏障前相关操作完成，常用于外设配置完成后再进行后续关键操作
ISB SY                 ; 刷新后续指令流水线，使后续指令按最新处理器执行环境重新取指执行

; 5.DMB典型场景：共享数据发布
STR R1, [R0]           ; 先写共享数据
DMB SY                 ; 保证共享数据写入先于后续状态标志写入被观察
STR R2, [R3]           ; 再写状态标志，避免其他处理器先看到标志而读到旧数据

; 6.DSB典型场景：进入等待前完成操作
STR R1, [R0]           ; 先完成外设或内存相关配置
DSB SY                 ; 等待此前相关操作达到规定的完成状态
WFI                    ; 确认操作完成后再进入中断等待状态

; 7.ISB典型场景：执行环境发生变化
DSB SY                 ; 先确保此前影响处理器状态的相关操作已经完成
ISB SY                 ; 清空后续流水线，使之后指令按新的执行环境重新取指执行

; 8.事件等待与通知
WFE                    ; 当前处理器进入事件等待状态
SEV                    ; 产生事件，通知等待事件的处理器继续执行
```
